# 课程数据格式规范（v2 数据驱动架构）

> 最终站点 = 数据驱动单页应用：所有课程内容以 JSON 数据存放，由 `assets/js/main.js` 渲染（含「教材与公开课 / 知识点讲义 / 分章练习 / 模拟套卷」页签）。**不再交付独立课程 HTML 页。**
> 子代理交付物：每门课一个 `data/<slug>.json` 文件（直接写入共享项目目录 `data\` 下）。
> 主代理合并所有 json → `data/courses.js`（`window.COURSES = [...]`）供页面加载，并另存 `data/courses.json`。
> **范例（必须精读并按此结构产出）**：
> - 数学类样例：`data/gaoshu.json`（高等数学，含 formulas 公式卡片）
> - 非数学类样例：`data/guanlixue.json`（管理学，无 formulas）

## 1. 课程对象（每个课程一个对象）

```json
{
  "id": "gaoshu",
  "name": "高等数学（甲）",
  "emoji": "📐",
  "category": "数理编程",
  "desc": "一句话课程简介（对应原卡片文案并可扩充）",
  "meta": ["学科大类基础课", "经管类必修", "微积分", "笔试课程"],
  "textbook": [
    {"role": "主教材参考", "title": "《高等数学（第七版）》（上、下册）", "pub": "同济大学数学系 编 · 高等教育出版社", "note": "查证状态说明或简介……"}
  ],
  "moocs": [
    {"platform": "中国大学MOOC", "name": "《高等数学》同济大学", "desc": "主讲/特点/与教材章节对应", "url": "https://真实链接"}
  ],
  "callout": "公开课知识点归类说明（HTML 片段，可省略为 \"\"）",
  "modules": [ …模块对象… ],
  "formulas": [ …公式卡片对象… ],
  "chapters": [ …分章练习… ],
  "papers": [ …模拟套卷… ]
}
```

### 字段规则
- `category` 必须取枚举值之一：`数理编程` / `经管核心` / `思政通识` / `成长通识` / `创业特色`。
- `meta` 为 2-4 个短标签（分类、必修类型、课程性质、是否笔试课等）。
- `textbook` 1-2 条；查证到官方指定教材写清楚；查不到必须写「杭电官网公开渠道未查到官方指定教材，以下为常用教材参考」字样（放 note 内）。
- `moocs` 2-3 条；`url` 必须是真实存在的公开课链接；无法核实的（如创业管理）允许写 `"url": "链接待核实"`，并在 desc 注明课程名与平台，不阻塞交付。
- `callout`：公开课对应知识点体系的归类说明（HTML 片段，允许为空字符串）。
- `formulas`：仅数学/统计类课程需要（8-12 条）；其余课程留空数组 `[]`。

### 模块对象（知识点讲义）
```json
{
  "index": "一",
  "title": "函数、极限与连续",
  "sub": "一句话导语",
  "sections": [
    {"h4": "1. 函数", "body": "正文知识点段落（多个 <p> 用 \\n 分隔；公式用 \\(…\\)）"}
  ],
  "terms": [
    {"name": "定义域", "plain": "通俗解释（必须有「通俗说/好比/像」类表述）", "example": "具体例子（数字、场景、算式，必须具体可感）"}
  ]
}
```
- 模块数 5-6 个，`terms` 每个模块至少 2-4 条。

### 公式卡片对象（仅数学/统计类）
```json
{"title": "导数基本公式", "math": "\\(…\\) 或 \\[…\\]", "note": "用途/记忆口诀"}
```

## 2. 分章练习（chapters）与模拟套卷（papers）

### chapters（分章练习）—— 章节必须与 modules 一一对应
```json
{
  "chapter": "第一章",
  "title": "函数、极限与连续",
  "hint": "本章知识清单：函数、复合函数、……。以下 5 选择 + 2 填空 + 1 大题覆盖全部知识点。",
  "knowledgePoints": ["函数", "复合函数", "数列极限", "函数极限", "无穷小量", "两个重要极限", "连续性", "间断点"],
  "questions": [ …题目对象… ]
}
```
规则：每一章都要给出该章的 选择题、填空题、大题（该章不适用的题型除外，并在 hint 中说明原因）；`knowledgePoints` 中**每一个知识点至少被一道题考察**；章内难度由易到难。

### papers（模拟套卷）—— 至少 2 套、建议 2-3 套，相互独立
```json
{
  "paper": "卷一",
  "title": "全书综合模拟（满分 100 分 · 建议 120 分钟）",
  "hint": "题型：一、选择题 10 题；二、填空题 6 题；三、计算/简答/论述题 4 题；覆盖第一至五章全部核心知识点。",
  "questions": [ …题目对象… ]
}
```
规则：覆盖整本书各章知识点；题型参照该课程真实考试题型（选择/填空/计算/简答/论述等）；每套卷子完整答案 + 详细解析 + 每题知识点标签；套卷之间相互独立。

### 题目对象（chapters 与 papers 共用同一结构）
```json
{
  "type": "选择题",
  "difficulty": "easy",
  "number": "第 1 题",
  "tags": ["函数", "定义域"],
  "stem": "函数 \\(f(x)=\\ln(x-1)\\) 的定义域是（　）。",
  "options": ["A. \\((0,+\\infty)\\)", "B. \\([1,+\\infty)\\)", "C. \\((1,+\\infty)\\)", "D. \\((-\\infty,1)\\)"],
  "answer": "<b>C</b>",
  "explain": "详细解析，步骤完整；对关键专有名词再做通俗解释+举例（<p> 用 \\n 分隔）",
  "kp": "📎 知识点：函数定义域 · 对数函数"
}
```
- `type` 枚举：`选择题` / `填空题` / `计算题` / `应用题` / `简答题` / `论述题`。
- `difficulty` 枚举：`easy` / `mid` / `hard`。
- `options`：仅选择题有，其他题型为空数组 `[]`。
- 填空题：`answer` 写完整答案；题干 `stem` 中空位用 `<span class=\"blank\">答案</span>` 标出（与样例一致）。
- 大题（计算/简答/论述）可含多个小问，用小问编号写进 `stem`。
- 每题必须：题干 + 答案 + 详细解析 + `kp` 知识点标签。

## 3. 文本与转义规则（重要）

- 字段里允许内嵌 HTML 片段（`<b>`、`<span class="blank">` 等），与样例 JSON 一致。
- HTML 文本中的 `<`、`>` 写成 `&lt;`、`&gt;`（含公式内部，如 `x&gt;1`）；`&` 写成 `&amp;`。
- 数学公式一律 `\(…\)`（行内）/ `\[…\]`（独立行），**禁止 `$…$`**；长公式可包 `<div class="math-scroll">…</div>`。
- JSON 字符串内嵌双引号用 `\"` 转义；反斜杠在 JSON 里要写成 `\\`（如公式 `\\(x\\)` 在 JSON 文件中显示为 `\\(x\\)`）。**产出后用 JSON 解析器校验一遍（见 §5）。**

## 4. 数量与质量要求（以本条为准，宁多勿漏）

- 模块 5-6 个；每个专有名词 `terms` 一条（通俗解释 + 具体例子）。
- chapters：每章 各题型齐全（不适用的题型说明）、每知识点至少一题、易→难。
- papers：至少 2 套、建议 2-3 套全书模拟卷，独立成套、完整答案解析。
- 全部简体中文、结构化；思政类表述严谨、符合主流教材口径。

## 5. 自检与回报（必须执行）

产出每个 `data/<slug>.json` 后执行：
1. **JSON 合法性**：`python -c "import json,io;json.load(io.open(r'文件路径',encoding='utf-8'))"` 不报错。
2. **结构检查**：chapters 章节数与 modules 数一致；knowledgePoints 每项都能在 questions 的 tags/kp 中找到；papers ≥ 2 套；每题有 type/difficulty/stem/answer/explain/kp。
3. **链接检查**：moocs 的 url 是真实公开课链接或「链接待核实」。
4. 回报格式（发给主代理）：
```
【已交付】每门课一行：课程名 | 文件绝对路径 | 模块数/章节数/套卷数 | 分章题量 | 卷面题量 | 教材查证状态 | 公开课数量 | 自检结果
```
